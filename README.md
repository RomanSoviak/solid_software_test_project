# Solid Software Test App

This Flutter application was developed as a test task for **Solid Software** company.

## Features

✅ Displays `"Hey there"` centered on screen.  
✅ Changes background color to a random color on screen tap.  
✅ Persists the last generated background color across sessions using `SharedPreferences`.  
✅ Includes basic unit tests example.  
✅ Handles color selecting error using `try/catch`.
